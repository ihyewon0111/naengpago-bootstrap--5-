# 🧊 냉파고 – 냉장고 털 각 나왔다 (웹사이트 버전)

> 냉장고 속 남은 재료를 담으면, **식약처 공공데이터**와 **AI 레시피**로 지금 바로 만들 수 있는 요리를 추천하는 자취생 요리 서비스

- **배포 주소**: https://(배포 후 입력).vercel.app
- **참가 분야**: AI로 만드는 맞춤형 추천 서비스
- **팀**: (팀명) · (이름/역할)

## 디자인
- Bootstrap v6.0.0-alpha.1 **Product 예제** 테마 적용 (`vendor/bootstrap.min.css`, 오프라인에서도 동작)
- 앱 전용 스타일은 `css/web.css`, 리포트 이미지 저장은 `vendor/html2canvas-pro.min.js`

## 화면 구성
| 영역 | 내용 |

## 데이터
| 데이터 | 출처 | 비고 |
|---|---|---|
| 조리식품의 레시피 DB (COOKRCP01) | 식품의약품안전처 식품안전나라 Open API | `scripts/collect_recipes.py`로 수집·정제 |
| AI 레시피 | 생성형 AI(Claude)로 작성 | 공공데이터에 없는 간단 자취 조합 보완, 화면에 출처 표시 |
| 재료 가격 | 예시 값 | (확인 후 출처 기입) |

## 추천 규칙
- **바로 가능**: 기본 양념을 뺀 재료를 내 냉장고에 전부 가진 요리만
- **1개만 사면**: 부족한 재료가 1개인 요리는 따로 표시
- 점수 = 커버율 + 빨리 써야 할 재료 사용 + 추가 비용 + 자취 적합도 + 냉장고 재료 활용도
- 오늘은 셰프(정성 요리 모드): 조리시간·재료 수·난이도로 계산한 정성 점수 우선

## 교내 GPU(틸론) 활용
- SDXL-Turbo로 냉파고 마스코트와 모드 캐릭터 생성 → 히어로·모드 카드·리포트에 사용

## 실행 방법
1. VS Code로 폴더 열기 → `index.html` 우클릭 → **Open with Live Server**
2. 레시피 데이터 다시 받기: `python scripts/collect_recipes.py --key 인증키 --rough`
3. 더블클릭으로 열 때를 위한 데이터 갱신: `python scripts/make_offline.py`
